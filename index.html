Flagship system

Handover Voice Summarizer
Production care-home platform

In production Employer project · Code private

A voice-first shift handover system for care homes, built at WhoopIt. Care workers record a short voice note about a resident; it's transcribed locally with Whisper, summarized into a structured report by Gemini, and anything urgent is pushed to managers instantly over WebSockets. It replaces rushed written notes with something faster and more complete.
